# 控制面板功能状态

## 已实现

- Dashboard：最近 30 天每日值和累计值
- 系统监控：数据库状态、WebSocket 连接数、运行时间、内存
- 数据库统计：用户、题目、提交、讨论和数据库大小
- 用户管理：分页、搜索、统计、删除
- 题目管理：分页、搜索、创建、读取、编辑、删除
- 测试数据：输入/答案上传、时间限制、内存限制和分数配置
- 中英文 React 界面
- 环境变量角色令牌、Bearer Token 和服务端逐路由授权
- 清空业务数据并保留 `control_panel_` 前缀表

## 尚未实现

- 比赛管理
- 讨论和题解审核
- 管理员管理 API
- 审计日志
- 数据备份与恢复
- 控制面板 API 端口自动发现
